# Household Carbon Footprint & Target Tracker

## Lab 1: Requirements Engineering & UML Use-Case Modelling

### Problem Statement

A green-living analytics tool where households log monthly electricity consumption (kWh), gas consumption, and commute distance (km) to compute CO₂-equivalent emissions and track reduction milestones.

### Actors

- Resident
- Sustainability Coach

### Deliverables

1. Complete Requirements Table
2. UML Use-Case Diagram
3. Use-Case Flow Specification

### Requirements

- 5 Functional Requirements: FR-001 to FR-005
- 2 Non-Functional Requirements: NFR-001 and NFR-002

### UML Relationships

- `<<include>>` — Enter Monthly Consumption includes Calculate Carbon Footprint
- `<<extend>>` — Generate Milestone Notification extends Track Reduction Progress

### Core Use Case

UC-01: Log Monthly Consumption and Calculate Carbon Footprint
